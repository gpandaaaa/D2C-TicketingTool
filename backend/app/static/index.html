Authentication

POST /api/v1/auth/login with email and password. The response sets an HttpOnly session cookie and returns a CSRF token. Include the cookie on subsequent requests and X-CSRF-Token on POST, PATCH, PUT, and DELETE requests. Password changes, administrator resets, role changes, and disabling an account revoke its sessions.

Use Idempotency-Key for retry-safe ticket creation. Reusing a key with different content returns HTTP 409. List endpoints return items, total, offset, and limit, except documented legacy asset/knowledge endpoints.

Errors use {"success":false,"error":{"code":"FORBIDDEN","message":"Insufficient permission"}}. Roles are loaded from PostgreSQL on every request. See endpoint schemas below for validation and supported fields.
